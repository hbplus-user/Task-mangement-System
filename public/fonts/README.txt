HB+ brand fonts (HB+ brand guidelines). Drop the licensed files here with these exact names
(.woff2 preferred, .otf also works):

  Primary — The Seasons (page titles, headlines)
    TheSeasons-Regular.woff2
    TheSeasons-Italic.woff2      (the italic accent words, e.g. "Good evening, *Riya*")

  Secondary — Gilroy (all app text, all weights)
    Gilroy-Regular.woff2   (400)
    Gilroy-Medium.woff2    (500)
    Gilroy-SemiBold.woff2  (600)
    Gilroy-Bold.woff2      (700)

  Tertiary — Astralaga Bold (small headings only: labels, section titles)
    Astralaga-Bold.woff2

Or, if the fonts come from Adobe Fonts, set VITE_ADOBE_FONTS_KIT=<kit id> in .env.local instead.
Check the licences cover web/app use.
Until the files are added, the app uses Playfair Display (for The Seasons) and Outfit (for Gilroy and Astralaga).
